# Raw Data Directory

Place your raw STED super-resolution images in this directory.

## Supported Formats

- TIFF (.tif, .tiff)
- PNG (.png)
- JPEG (.jpg, .jpeg)

## Organization

You can organize your images in subdirectories as needed:

```
raw/
├── experiment1/
│   ├── image1.tif
│   └── image2.tif
├── experiment2/
│   ├── image1.tif
│   └── image2.tif
└── controls/
    ├── control1.tif
    └── control2.tif
```

## Note

These files should be your original, unprocessed STED images.
